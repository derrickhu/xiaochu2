# xiaochu2 体验目标（设计北极星）

> **本文件优先于一切玩法、数值、系统、商业化文档。**  
> 后续任何设计、改需求、加系统，都必须先用本文「审视清单」过一遍；通不过则改方案或砍掉，而不是改体验目标去迁就功能。

---

## 1. 主体验目标

**正式表述**

> 当喜欢轻度动脑的玩家在碎片时间推关时，反复感到：**「这关是我换对了宠物/属性才过的」**——赢来自搭配想明白，而不是把等级堆上去。

**一句话**

> **编队聪明感：靠克制与站位读关，而不是靠肝度碾关。**

**玩家应脱口而出**

- 「换土系就过了」
- 「这队终于对上了」
- 「原来是属性没克上」

---

## 2. 反目标（坚决避免）

玩家若经常感到以下任一，即体验目标失败：

| 反目标感受 | 典型诱因（设计上要挡） |
|---|---|
| 「伤害不够，再升两级再说」 | 纯数值墙、克制收益被等级差淹没 |
| 「系统太多，不知道该养成啥」 | 多条养成线、资源目标冲突 |
| 「抽不到就过不去」 | 黑箱强依赖、过关绑限定高稀有 |
| 「每关都一样，换不换队无所谓」 | 关卡无属性/机制差异、编队无反馈 |

---

## 3. 体验结构（主 / 辅）

| 层级 | 内容 | 说明 |
|---|---|---|
| **主** | 编队聪明感（Challenge） | 关卡属性/机制 ↔ 宠物属性与队伍构成 |
| **强辅** | 转珠 Combo 手感（Sensation） | 让「搭配正确」的结果打得爽、看得懂；不抢主目标 |
| **弱辅** | 招募收集 | 给「换队」提供弹药与覆盖面；完成欲服务编队，不是主爽点 |

聪明感的**关键时刻**：卡关 → 调整队伍/属性 → 再通关。  
若玩家卡关后第一反应是「去强化」而不是「换队」，主目标已偏。

---

## 4. 游玩情境（设计约束）

- 平台：微信 / 抖音小游戏
- 场合：单人、碎片时间
- 单关：数分钟内可结束
- 教学重点（新手前几关）：转珠 = 攻击 → 连击 = 高伤 → **宠物搭配过关**

---

## 5. 设计审视清单（必过）

新增或改动玩法 / 数值 / UI / 商业化前，逐条回答。任一条为「否」且无法修正 → **不做或降权**。

1. **卡关路径**：玩家卡住时，游戏是否把「换队 / 补克制属性」提示为比「纯升级」更清晰、更短的路径？
2. **胜利归因**：通关反馈是否让人感到「搭配对了」，而不是只感到「战力够了」？
3. **克制权重**：属性克制与编队差异，是否足以改变一关的结果？（不能被等级差完全抹平）
4. **养成服务编队**：新养成/新资源，是否扩大「可搭配的选择」，而不是只加一条与编队无关的战力轴？
5. **系统负担**：是否增加了让玩家忘记「换队」的干扰目标？（多养成、多货币、复杂任务）
6. **付费/广告**：变现是否制造「不抽/不付就无法靠搭配过关」？若是，违反反目标。
7. **辅系统边界**：转珠手感、招募、演出强化的是「读关 + 编队」，还是在单独抢戏？

---

## 6. 加 / 慎 / 砍（速查）

| 倾向 | 例子 |
|---|---|
| **加** | 关卡主属性提示、克制推荐、编队对比、「因克制通关」结算文案、卡关引导换队 |
| **慎加** | 第二条养成线、纯战力榜、无属性意义的强度宠、自动战斗淡化操作与搭配感知 |
| **砍 / 降权** | 任何让「升级」比「换队」更短路径的设计；黑箱绑关卡的强抽；与编队无关的系统堆叠 |

与 [01-核心玩法循环](./01-核心玩法循环.md) 的关系：核心循环里的「五行克制软墙」「灵宠币只服务招募」等，都是本体验目标的手段，不是更高优先级的目标。

与 [02-数值框架](./02-数值框架.md) 的关系：克制倍率、关卡难度、成长曲线调参时，以「换队能过、纯堆等级不是唯一解」为验收，而不是只看战力曲线平滑。

---

## 7. 验收标准（体验是否达标）

| 阶段 | 标准 |
|---|---|
| 新手 | 前几关后，玩家能说出「属性/队伍有用」 |
| 卡关 | 抽样：卡关时第一意图偏向换队或补属性，而非只肝等级 |
| 通关 | 结算或引导中出现可理解的「搭配/克制」归因（文案或 UI） |
| 回归 | 大改数值或加系统后，重跑本清单第 5 节 |
