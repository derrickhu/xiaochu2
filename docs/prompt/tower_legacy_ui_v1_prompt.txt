Mobile game UI prototype mockup, 9:16 portrait, NO phone frame, NO watermark.

MATCH STYLE of reference images (jiling path picker / bless picker):
- Warm guofeng / Q cultivation mobile game UI
- Cream parchment panel, soft gold ornate thin border, jade-green accent corners
- Misty mountain + distant pagoda backdrop behind dim scrim (blurred, atmospheric)
- Soft cel-shaded illustration language, cute but refined — NOT photoreal, NOT dark neon, NOT purple

SCREEN PURPOSE:
「传承」meta-upgrade shop — spend permanent currency「登塔印记」on quality-of-life for future tower runs.
Does NOT buy attack/defense power.

TILE RULES:
- Each tile: cream inset card, soft gold hairline, LEFT circular icon (illustrated, not emoji), RIGHT text stack
- Name bold brown; effect in darker readable gray-brown, short plain Chinese
- Bottom-right small cost chip with tiny seal glyph
- Level dots under name when multi-level
- NO dense walls of identical white boxes; icons create instant recognition
- One tile may show slight gold glow as "affordable / recommended" (e.g. 重掷 200)

FOOTER micro line inside modal bottom:
「点条目消耗印记升级 · 点满仍可去「兑换」花印记」

ABSOLUTELY AVOID:
- Flat plain white identical cards with only text (that's the bad current UI)
- Purple/neon/cyberpunk
- Dashboard clutter, tiny unreadable paragraphs
- English UI chrome, watermarks, phone bezels
- Selling ATK/DEF power fantasy in the copy

Chinese labels required throughout. High-fidelity game UI mock, polished, readable on mobile.
