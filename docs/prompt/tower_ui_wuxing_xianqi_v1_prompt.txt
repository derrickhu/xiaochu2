1) Current game screenshot — keep ONLY the functional layout skeleton (back / title / tower hero / right status / milestone strip / challenge CTA / bottom 5-tab nav). Do NOT keep the cute mint-cream casual look.

ART DIRECTION:
- Mature soft-painted xianxia (玄幻仙气), elegant, mystical, premium mobile game quality

  · 木 Wood: jade-green glazed tiles, vine/leaf motif subtle
  · 水 Water: cyan-blue roof glaze, soft ripple light
  · 火 Fire: warm crimson-orange eaves, ember glow in windows
  · 土 Earth: amber-ochre stone body bands, grounded base
- Around mid-tower: a large translucent five-element spirit ring / Taiji-adjacent celestial circle (inspired by reference mandala), segmented into 5 colored arcs (gold / green / blue / red / ochre), soft rune glow — NOT text
- Tower floats above cloud sea; faint spirit particles and light shafts
- Grand, sacred, ascending-to-heaven feeling

BACKGROUND:
- Full-bleed immortal realm: misty mountains, floating islets with pines, cloud ocean, dusk star-haze
- Soft depth; leave clear readability for UI chrome
